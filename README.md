# E-Commerce Customer Behavior & Funnel Analysis
SQL-based analysis of customer behavior, purchase funnel performance, cart abandonment, revenue, and product performance using MySQL.

## Project Overview
This project analyzes 25,000 e-commerce customer sessions records to understand customer behavior, purchase conversion, cart abandonment, revenue performance, and factors affecting the overall sales funnel.

## Business Questions

### E-commerce Funnel Analysis
- What is the total number of customer sessions?
- How many sessions resulted in a product being added to the cart?
- How many sessions resulted in a purchase?
- What is the overall purchase conversion rate?
- What percentage of cart additions result in abandonment?

### Customer & User Type Analysis
- How does purchase conversion differ between user types?
- Which user type generates more purchases?
- How does cart abandonment vary across user types?
- How does revenue differ between user types?
- How does average order value differ between user types?

### Device & Marketing Channel Analysis
- How does purchase conversion vary across device types?
- Which device type has the highest conversion rate?
- How do marketing channels compare in terms of conversion rate?
- Which marketing channels generate the highest revenue?
- How does average order value vary across marketing channels?

### Product Category Analysis
- Which product categories generate the highest revenue?
- Which product categories have the highest purchase conversion rate?
- Which product categories have the highest add-to-cart activity?
- Which product categories have the highest cart abandonment rate?
- Which categories show high customer interest but lower purchase conversion?

### Cart Abandonment Analysis
- What is the overall cart abandonment rate?
- How does cart abandonment vary across user types?
- How does cart abandonment vary across product categories?
- How many cart additions result in abandoned sessions?

### Revenue & Sales Performance
- What is the total revenue generated from purchases?
- What is the total number of orders?
- What is the overall average order value?
- How does revenue vary across user types?
- How does revenue vary across marketing channels?
- How does revenue vary across product categories?
- How does the number of orders vary across marketing channels?
- How does the number of orders vary across product categories?

### Customer Engagement Analysis
- How does the number of pages viewed relate to purchase conversion?
- Which engagement level has the highest conversion rate?

### Payment Method Analysis
- How does revenue performance vary across payment methods?
- Which payment methods generate the highest revenue?
- How does average order value vary across payment methods?
- How does the number of orders vary across payment methods?

## SQL Analysis
The project uses MySQL to analyze customer behavior, funnel performance, revenue, and purchase patterns through multiple SQL queries.

- Cart Abandonment Analysis
